# A-cryptographically-secure-password-generator-by-DevGeek.IT
Генератор надёжных паролей от DevGeek.IT создаёт криптографически стойкие пароли любой длины. Использует системный CSPRNG, поддерживает наборы символов (A–Z, a–z, 0–9, спецсимволы), исключает неоднозначные знаки и повторяющиеся шаблоны. Работает офлайн, без телеметрии. Подходит для защиты аккаунтов, баз данных и скриптов автоматизации.
